FIX 2 — Pass ID format per type
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

In POST /api/admin/access/single, generate the pass ID based on the pass type selected:

If passType = "General Entry":
- Format: ACC-SE[NUMBER]
- NUMBER = count of all existing admin_single General Entry passes + 1, zero-padded to 3 digits
- Example: ACC-SE001, ACC-SE002, ACC-SE003

If passType = "Table for 4" or "Table for 5":
- Format: ACC-[TABLE_NUMBER]001
- TABLE_NUMBER = the table number the admin assigned
- Example: Table 3 → ACC-3001

If passType = "Section":
- Format: ACC-S[SECTION_NUMBER]001
- SECTION_NUMBER = the section number the admin assigned
- Example: Section 2 → ACC-S2001
