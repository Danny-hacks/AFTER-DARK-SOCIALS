In generatePassCanvas.ts, calculate the photo height 
dynamically to match the total fields section height 
instead of using a fixed value.

Replace the fixed photoH value with a calculated one:

Current:
const photoH = 220

Replace with:
const fieldSectionHeight = (CARD_H - footerHeight - bodyStartY - 20)
const photoH = fieldSectionHeight

Where:
- bodyStartY = photoY (where the body section starts, e.g. 165)
- footerHeight = approximately 90px from the bottom
- So: photoH = CARD_H - 90 - photoY - 20

This makes the photo box grow or shrink to exactly match 
the height of all 4 fields stacked together.

Also update the image drawing to fill the full new photoH:
ctx.drawImage(img, photoX, photoY, photoW, photoH)

And the silhouette placeholder positioning to remain 
centered within the new taller box.
