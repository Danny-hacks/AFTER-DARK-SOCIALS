Generate the pass ID server-side using the same format as the reservation flow:
ACC-[TABLE_NUMBER][GUEST_NUMBER]

For single entry passes:
- TABLE_NUMBER = the table number the admin assigns
- GUEST_NUMBER = 001 (since it is a single entry, always 001)

Example:
- Admin issues a single pass for Table 3 → ACC-3001
- Admin issues a single pass for Table 1 → ACC-1001

Use html2canvas to capture the PassportCard component as a PNG image.
Then use jsPDF to convert the PNG into a downloadable PDF.

Install both packages:
npm install html2canvas jspdf

Implementation:
- Add a "Download Pass" button below the passport preview in both:
 a. The admin single pass generator
 b. Each approved reservation in the admin reservations list

- On click:
 1. Use html2canvas to screenshot the PassportCard DOM element
 2. Convert to PDF using jsPDF (A6 landscape size — 148mm x 105mm — standard card size)
 3. Trigger browser download as: "ACCESS-PASS-[PASSID].pdf"

PDF settings:
- Page size: A6 landscape (148 x 105mm)
- No margins — passport card fills the full page
- Filename: ACCESS-PASS-[PASSID].pdf

Since WhatsApp does not support sending files via wa.me links, use a two-step approach:

Step 1 — Auto-download the pass PDF to admin's device
Step 2 — Open WhatsApp to the guest's number with this pre-filled message:

"Your ACCESS pass is confirmed.

Name: [NAME]
Table: [TABLE TYPE]
Date: 27 July 2026
Pass ID: [PASSID]

Your pass has been attached to this message.

After Dark Socials · @afterdarksocials.mu"

This means:
- The PDF downloads automatically to the admin's device
- WhatsApp opens to the guest's number
- Admin manually attaches and sends the downloaded PDF in the chat
